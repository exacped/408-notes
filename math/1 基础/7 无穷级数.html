这里用求导来做：

然后对-1/x 展开成 x - 1，那么求导之后还是含有 x - 1 的式子

这里需要注意求和符号的下标，我们求导的时候是直接将原函数的通项中的 n 看作常数，然后对这个通项求导，这个直接对通项求导就意味着我们求导是对原级数的一项项对应求导得到求导后的级数的

求导后级数的通项是原来对应的第 n 项通项求导的结果，所以符号下标也应该与原来的下标保持一致，因为是一项项对应求导过来的，每一项都应该满足求导对应关系

但是函数展开成幂级数的含有 x 项的次数一般是从 0 开始的，这里求导之后求和符号的下标如果还从零开始那就会出现-1 次方，显然不行

观察求导前原来的第 0项，发现是个常数，所以求导后得到级数的第 0 项可以直接消去了，所以求导之后的下标可以直接从 1 开始了

处理级数求导或者积分之后的求和下标的步骤方法：

（1）直接将通向中的 n 看作常数，然后对通项进行求导或者积分处理；这一步做法的意义就是对原级数的每一项挨个求导或者积分成目标级数，并且保证一一对应关系，所以求和符号的下标也应该保持一致，原级数中的第 0，1，2... n 项对应为目标级数的第 0，1，2.... n 项

（2）观察原级数和目标级数的前几项，看在求导过程中是否丢失，如果丢失的话目标级数的求和符号不应该从下标 0 开始，应该从下标 1 之后开始，此时原级数和目标级数还是一一对应关系，只是目标级数可能少了前几项，下标不是从 0 开始：
