3 函数极限的保号性性质判断

第一个，显然错，不能加上等号
第二个，f (x) >= 0 的时候 lim f (x) >= 0，加上等号才对，没有等号错误，比如函数 x^2 去掉 x = 0 这个点的函数
第三个，这里没有说极限存在，只有两个函数的极限存在的时候这个命题才正确
第四个，正确，就是函数极限保号性的推论，注意这个命题反过来的话跟第三个命题是一样的，应该加上等号

（1）极限等于 a (a>0)，则有领域 f (x) > 0，这里 a 不能带等号，带了等号领域中 f (x) 的正负未知
（2）反过来，在一个领域中 f (x) >= 0，则如果 f (x) 极限存在 = a，则 a >= 0，这里不论 f (x) 有没有等号，极限 a 必须带上等号
（3）如果极限 lim f (x) > lim g (x)，则一定存在一个领域，f (x) > g (x)，这里极限不能带等号，带了等号两个函数的大小未知
（4）反过来，f (x) >= g (x) 则一定有极限 lim f (x) >= lim g (x)，这里不论 f (x) 和 g (x) 有没有等号，极限的比较必须带上等号

总结就是极限的符号（不带等号）可以确定函数在领域是否带等号，但是函数在领域的符号无法确定极限是否带等号

无穷小及其阶数

14 易错点：同阶无穷小没有高阶无穷小的运算性质 + 不同阶无穷小的运算性质

这道题目不能这样做：即如果 b = 1，那么 x - tanx 是三阶无穷小，然后 a + cx^2+dx^3 也是 x^3 的同阶无穷小，所以整体是 x^3 同阶无穷小，不是 x^3 的高阶无穷小，所以 b 不能等于 1；这种做法的错处在于同阶无穷小运算之后可能消去某些项，其无穷小阶数可能会发生变化的

比如 x3−sinx3，这两项都是 x^3 的同阶无穷小，但是运算之后消掉了 x^3就变成了 x^6 的同阶无穷小，同阶无穷小并没有高阶无穷小加减的吸收性质

但是如果两项是不同阶的，则跟高阶无穷小的运算性质一样，仍然是低阶的吸收高阶的，比如 x2+x6，这个式子整体是与 x2 同阶的无穷小

无穷小总结：
（0）一般一个式子有自己的无穷小阶数，如果说它是 x^k 的高阶无穷小的话，记作 o (x^k)，但是其阶数不是k 阶，一般无穷小的运算性质是指高阶无穷小的运算
（1）如果 f (x) 和 g (x) 可以确定阶数并且不是同阶无穷小的话，两者加减乘符合高阶无穷小的运算性质，即低阶吸收高阶，乘起来其无穷小的阶数也会相乘，可以确定运算之后的无穷小阶数
（2）如果 f (x) 和 g (x) 可以确定阶数并且两者是同阶无穷小的话，乘可以，但是加减不好说，不能确定最后结果的无穷小阶数，因为 f (x) 和 g (x) 中的低阶可能直接抵消了，最后阶数可能变大，最好的方法是将 f (x) 和 g (x) 写成确定的阶数跟上一个高阶无穷小的尾巴，然后代换进行计算比如下文 16 题，比如 x^3 - sin x^3
（3）如果 f (x) 和 g (x) 不能确定阶数，只知道是某个阶数的高阶无穷小，那么直接按照高阶无穷小的运算性质计算即可，最后只能确定为某个高阶无穷小，具体的阶数无法确定

首先，题目中说了极限存在，那么可以在草稿上根据 xn+1​6+xn​​ 两边取极限算出来极限 A = 3 or -2；由于是根号，所以-2 舍去

（1）答题通法
于是答题的时候就围绕单调减，并且有下界来证明

首先证明有界，一般而言我们求出的极限 3 就是下界，所以可以直接利用数归来证明 xn >= 3，这个很容易证明，不再赘述

这里证明单调递减的时候可以做除法 xn​xn+1​​ 根据 xn 的有界性可以发现这个是小于等于 1 的，所以是递减的

这种题目一般就是从单调性和有界性两个方面证明，但是在草稿上我们可以先求出极限，然后猜测递增还是递减，利用极限作为上界或者下界证明有界，然后利用有界性证明单调

（2）证明单调性的方法

这里还可以作差证明，即证明 xn+1​−xn​≤0，将 xn+1 的表达式代入并有理化，于是我们要证的就转化为：6+xn​​+6+xn−1​​xn​−xn−1​​≤0​，那么对于 xn - xn-1 我们继续往前递推，要证的就转化为 xn-1 - xn-2 <= 0，这样一步步转化为要证 x 2 - x 1 <= 0，显然这个是成立的，于是反推回去 xn+1​−xn​≤0 就成立，有点类似于数归

结论：对于 xn+1​=f(xn​) 这样的式子一般都可以用上述方式证明，对于 xn+1​=f(xn​)，如果 f 是单调递增的，那么{xn}这个数列就是单调的，至于单调增还是单调减取决于 x 2 和 x 1，如果 x 2 > x 1 那就是单增，如果 x 2 < x 1 那就是单调减

这个结论的正确性在于，xn+1 - xn 可以写成 xn+1​−xn​=f(xn​)−f(xn−1​)，那么如果 f 是单调增的，那么这个差值的正负就取决于 xn 和 xn-1 的正负，而 xn 与 xn-1 作差又可以继续往前取决于 xn-1 和 xn-2 的正负，一直递推到 x 2 - x 1，当 x 2 - x 1 > 0 的时候由于 f 单调增，因此 f (x 2) - f (x 1) > 0，因此推出 x 3 > x 2，继续推出 x 4 > x 3 一直推出 xn+1 > xn，那么 {xn}就是递增的了

如果 xn+1 = f (xn) 中 f 是单调减的，那么{xn}一定不单调

下面开始证明分析有界性

既然 yn 是递减，那么就要找到其下界，即 yn >=某个数，此时显然要与 x 1 = a, y 1 = b 扯上一些关系，根据 yn >= xn 于是可以得到 yn >= xn >= x 1；同理得到 xn <= y 1 <= b，所以{yn}， {xn}的极限都存在

对题目中给出的关系两边取极限就得到结果了

23 间断点的判断

25 最值定理的使用 + 根据极限定义构造闭区间

由于最值定理是用在闭区间的，所以这里我们必须要找到一个闭区间，看到极限，我们想办法根据极限构造一个闭区间

由于左极限是趋于负无穷，因此对于任意一个整数 C，一定有 x 1，使得 x < x 1 的时候 f (x) < C
同理对于右边，对于任意一个整数 C，一定有 x 2，使得 x > x 2 的时候 f (x) < C

假设取 C = f (x 0)，那么就一定存在一个 x 1, f (x) < x 1 的时候 f (x) < f (x 0)；一定存在一个 x 1，f (x) > x 2 的时候 f (x) < f (x 0)

即存在区间[x 1, x 2]，这个区间中的 f (x 0) = C 会大于这个区间外的所有值

而 f (x) 又在[x 1, x 2]连续，所以在这个区间中一定会有最值 M >= C，这个最值同时大于这个区间和这个区间外的所有值，这个就是整体最值了
