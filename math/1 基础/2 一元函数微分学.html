20 泰勒公式的展开式系数 ak 与原函数的 k 阶导关系 + 泰勒公式求 k 次项系数 ak 的方法

这道题目简单，但是其背后的思想是泰勒公式的原函数与展开式的对应关系，首先，将函数展开为幂级数的形式：

f(x)=a0​+a1​(x−x0​)+a2​(x−x0​)2+…⋯+an​(x−x0​)n+o((x−x0​)n)

然后有一个对应关系是，函数 f (x) 在 x 0 处展开，要求多项式在 x 0 处的 k 阶导数与 f (x) 在 x 0 处的 k 阶导数一样，并且这个多项式在 x 0 处的值也是一样

根据这个对应关系，多项式在 x 0 处的 k 阶导数，就是 k 次项求 k 阶导数暴露出来的常数项，这一项与函数 f (x) 在 x 0 处的 k 阶导数一样，即：

(ak​(x−x0​))(k)∣x0​​=ak​k!=f(k)(x0​)

比如 n 阶导要求一样，那么多项式求 n 阶导，n 次项左边的项会因为是常数全部消掉，n 次项右边的项因为还有 (x - x 0) 这一项所以代入 x 0 的时候就是零，因此剩下的就是 n 次项求 n 阶导的结果 an​n!，这个应该与 f (x) 在 x 0 处求 n 阶导的结果一样，即 f(n)(x0​)，从而得到系数：an​=n!f(n)(x0​)​

通用过程就是：
（1）先写出式子 f(x)=a0​+a1​(x−x0​)+a2​(x−x0​)2+…⋯+an​(x−x0​)n+o((x−x0​)n)
