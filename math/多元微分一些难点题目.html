0 链式法则

一般来说就是异路相加，同路相乘

对于一元复合函数 z=f(u),u=ϕ(x)，这类也满足这样的规则，z 对 x 求导就是同路相乘

1 关于位置的形式一致

对于 f (x, y); f (u, y); f (x+y, 2 x)，这三种 f 的表达式，他们的形式是一样的，都是关于第一个位置和第二个位置的函数，因此当这三者两个位置的值相等时，结果相等

即 x = 1, y = 2, f (x, y) = A 的时候

那么当 u = 1, v = 2 的时候同样有 f (u, v) = A

当x + y = 1, 2 x = 2 的时候同样有 f (x+y, 2 x) = A

具有相同映射关系的两个表达式，不管实际上是什么变量的函数，只要映射关系一样，那么其关于位置的表达式就是形式一致的，对位置求导之后的表达式关于位置变量的形式也是一致的，所以当位置取值相等的时候，函数值也就相等

比如，对于两个映射关系一样但是复合函数不一样的两个函数，比如 f (u, v), f (x, y)，这里假设 u, v 都是关于 x, y 的函数，即 f (u (x, y), v (x, y)), f (x, y)

只要映射关系一样，那么这个映射关系对位置求导的形式就是一样的

也就是说 f1′​(u,v) 与 f1′​(x,y) 的中，将 f1′​(u,v) 看作 u, v 的函数的表达式，其与 f1′​(x,y) 看作 x, y 的表达式的区别仅仅在于未知数的符号不一样，形式完全是一致的，那么当 u = 1, v = 1，x =1, y = 1 的时候这两个偏导数的值就是一样的即 f1′​(u,v)=f1′​(x,y)

f2′​(u,v) 与 f2′​(x,y) 也是这样

5 先带后求的问题

一阶偏导先带后求不用多说，即 ∂y∂u(x,y)​∣(x0​,y0​)​ 一定是先代入 x 0 到 u (x, y) 中然后对 y 求偏导，这个式子的含义就是 u (x, y) 在 x = x 0 的情况下，u (x 0, y) 对 y 在 y 0 处的导数

二阶混合偏导先带后求，比如求 ∂x∂y∂2u​∣(x0​,y0​)，这个式子的含义是 ∂x∂u​(x,y) 这个关于 x, y 的函数, 在 x = x 0 的情况下，∂x∂u​(x0​,y) 对于 y 在 y 0 处的导数

所以我们一定是先求出 ∂x∂u​，这是一个关于 x, y 的函数，然后再使用先带后求，一定是在一阶导中代入值 x 0 然后求偏导，所以此时先带后求就是先将 x 0 代入 ∂x∂u​(x,y) 这个关于 x, y 的函数中，然后再对 y 求偏导

而不能一开始对 x 求偏导的时候就代入 y 0，这样做是错的，前面代入 y 0 后面就没办法求二阶偏导了，而且也不符合这个式子的含义
