数列极限收敛准则（主要是单调有界）

事实上只要数列单调增有上界，那么极限就存在；或者单调减有下界，那么极限就存在（单调有界准则）

证明有界的常用方法

（1）常用不等式，基本不等式，或者常用的 ln 和 e 的不等式

（2）数归，根据第一项代入式子的范围，假设第 xn-1 项的范围，然后根据式子得到 xn 项的范围

（2）作商

（4）递推函数法：如下

递推函数法证明数列单调性方法

结论：对于 xn+1​=f(xn​) 这样的式子一般都可以用上述方式证明，对于 xn+1​=f(xn​)，如果 f 是单调递增的，那么{xn}这个数列就是单调的，至于单调增还是单调减取决于 x 2 和 x 1，如果 x 2 > x 1 那就是单增，如果 x 2 < x 1 那就是单调减

这个结论的正确性在于，xn+1 - xn 可以写成 xn+1​−xn​=f(xn​)−f(xn−1​)=f′(ξ)(xn​−xn−1​)，那么如果 f 是单调增的，所以 f′(ξ)>0，所以这个差值的正负就取决于 xn 和 xn-1 的正负，而 xn 与 xn-1 作差又可以继续往前取决于 xn-1 和 xn-2 的正负，一直递推到 x 2 - x 1，当 x 2 - x 1 > 0 的时候推出 x 3 > x 2，继续推出 x 4 > x 3 一直推出 xn+1 > xn，那么 {xn}就是递增的了

如果 xn+1 = f (xn) 中 f 是单调减的，那么{xn}一定不单调

罗尔定理和拉格朗日定理的三点图处理方法

罗尔定理的三点图和拉格朗日三点图：
（1）罗尔定理三点图的前提条件是三个函数值为零，罗尔定理三点图得到的导数和二阶导是等于零的信息

（2）拉格朗日三点图的前提条件是两个函数相等，一个函数在这两个函数的上方或者下方，拉格朗日三点图得到的是导数和二阶导是不为零的信息

（3）两者都需要连续使用三次定理（两层），并且连续两层定理的结构是完全一致的，都是两个函数点之间使用一层定理得到两个导数信息，然后两个导数对应的点之间再用一层定理，得到二阶导的信息

拉格朗日三点图

仍然是在 (a, c)，(c, b) 使用两次拉格朗日中值定理

f′(ξ1​)(c−a)=f(c)−f(a);f′(ξ2​)(b−c)=f(b)−f(c)

所以 f′′(ξ3​)<0
