极值点和拐点和驻点的定义

极值点的定义是：

x 在 x 0 的一个邻域中 f (x) > f (x 0) 则 x 0 是极小值点，极大值点也是这样定义

此处是严格小于，并且不要求 f (x) 在 x 0 处可导，也不要求 f (x) 在 x 0 处连续，只要有定义即可

拐点的定义：

连接 f (x) 凹弧和凸弧的点，即 f (x) 一阶导单调性变化的点

此处 f (x) 必须在拐点 (x 0, f (x 0)) 处连续，但是拐点处的一阶导可以不存在

驻点的定义：

使得函数的一阶导 f′(x)=0 的点是驻点

驻点不一定是极值点，极值点也不一定是驻点，不过加上可导之后，极值点当然就是驻点，但是驻点还是不一定是极值点

（2）f (x) 在 x 0 二阶可导，在 x 0 处 f' (x) = 0， f'' (x) != 0，则 x 0 是极值点

（3）f (x) 在 x 0 n 阶可导，在 x 0 处前 n-1 阶导全部为 0，且 f(n)(x0​)=0，如果 n 是偶数，则 x 0 是极值点

拐点的充分条件：

（1）连续函数 f (x)，在 x = x 0 两侧 f'' (x) 异号，则 (x 0, f (x 0)) 是 f (x) 的拐点，如果在 x = x 0 两侧 f'' (x) 不异号，则不是拐点（数分教材原话）

这里必须连续，如果不连续，则不是拐点

（2）f (x) 在 x = x 0 的领域内三阶可导，且 f'' (x 0) = 0，f''' (x 0) != 0，则 (x 0, f (x 0)) 是 f (x) 的拐点

（3）f (x) 在 x 0 n 阶可导，在 x 0 处从二阶导到 n-1 阶导全部为 0，且 f(n)(x0​)=0，如果 n 是奇数，则 (x 0, f (x 0)) 是 f (x) 的拐点

极值点和拐点的必要条件

极值点的必要条件

f (x) 在 x 0 可导，并且在 x 0 处取得极值，则 f' (x 0) = 0

反过来不行，比如常函数

极值可以在驻点，或者一阶导不存在的点取得

拐点的必要条件：

f (x) 在 x 0 有二阶导数，并且在（x 0, f (x 0)）处是拐点，则 f'' (x 0) = 0

反过来不行，比如常函数

拐点可以在 f'' (x) = 0，或者二阶导不存在的点取得

极值点和拐点的计算方法和区别

极值点的计算方法：

极值只可能在驻点或者不可导点中取得，因此我们挨个考察驻点和不可导点，对这些点挨个使用充分条件，判断左右两侧符号，如果异号则是极值点，如果同号，则不是极值点

当然有可能三大充分条件全部失效 （一般题目不会出这样的）比如 f (x) 在 x 0 处不连续，此时可以用定义来考察这个点

拐点的计算方法：

根据拐点的必要条件，拐点只可能在二阶导等于零和二阶不可导点中取得，因此我们挨个考察这些点两侧二阶导的符号，如果异号则是拐点，如果同号则不是拐点

当然有可能这个点不是 f (x) 的连续点，不连续那肯定就不是拐点（不满足定义）

极值点和拐点第一充分条件使用前提的区别和联系

（1）极值点要求 f (x) 在 x 0 处必须连续才能使用第一充分条件，如果不连续则应该用定义判断；拐点也要求在 x 0 处连续才能使用第一充分条件，如果不连续就不符合拐点定义，肯定不是拐点

（2）同时拐点第一充分条件的使用并不要求一阶导在 x 0 处连续，极值点的第一充分条件也不要求一阶导在 x 0 处连续

第一充分条件一般是选填中判断极值点和拐点的最常用方法，只要函数连续，就可以使用，如果不连续，那么无论是极值点还是拐点的判断方法全部失效，这个点是否是极值点得用定义，并且一定不是拐点

极值点和拐点对原函数，导函数，二阶导的存在性要求

极值点

极值点必须要求原函数在 x 0 处存在，不要求原函数 f (x) 在 x 0 连续，也不要求导函数，二阶导在 x 0 处存在

拐点

拐点必须要求原函数在 x 0 处连续，不要求导函数，二阶导在 x 0 处存在

因此在图像判断极值点和拐点的时候，一般给出的是 f' (x) 和 f'' (x) 的图像，这个图像中的不存在的点也要用充分性进行考察

极值点和拐点的联系和区别

拐点和极值点的联系和区别

（1）f (x) 在拐点处必须连续，但是 f (x) 在极值点处不一定连续

（2）拐点处的一阶导可以不存在，极值点处的一阶导也可以不存在

（3）一个函数的拐点和极值点可以同时取得，但是此处的导数一定不存在，这个函数的脑袋一定是尖尖的，对于函数的可导点，极值点和拐点无法同时取得

（4）拐点不能简单看作是一阶导的极值点，因为此处的导数可以不存在，比如上面脑袋尖尖的函数；这是因为拐点本质上来说是原函数 f (x) 的性质，是连接一段凹一段凸的点，这个点处当然可能函数导数不存在

（5）判断极值点是找到一阶导等于零和不存在的点；判断拐点是找到二阶导等于零和不存在的点；判断方法都是观察两侧的一阶导和二阶导符号，变号则是极值点或者拐点，不变号则不是极值点或者拐点；区别在于当 f (x) 在 x 0 不连续，第一充分条件判定失效，此时判断极值点的时候需要用定义，而拐点可以直接根据不连续判定 x 0 不是拐点
