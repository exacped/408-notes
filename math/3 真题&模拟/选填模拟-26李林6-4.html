1 复杂的函数复合的泰勒展开

这道题涉及的是 g(x)f(x)​ 这种的除法形式的泰勒展开

这类题目的出法一般是令 g(x)f(x)​=h(x)，然后 h (x) 含有一些参数

处理方式是两边成 g (x) 转换成乘法的形式：

f(x)=h(x)g(x)

然后分别对 f (x) 和 g (x) 进行泰勒展开，系数对应相等来弄出系数

或者按照定义：

x→0lim​x5(cotx−x+bx31+ax2​)​=0

然后对这个分式进行上下同乘处理变成：

x7+bx9cosx(x+bx3)−(1+ax2)sinx​=0(x→0)

这样处理同样正确（实际上是一样的处理手段），对分子进行泰勒展开处理，此时分母是 7 阶，因此分子也要展开到 7 阶

这里分子的 x 7 次方之下的幂次的系数必须全部为 0，根据此来求出系数

这里分子中 x^3 的系数是：

(−21​+b+61​+a)

x^5 的系数是：

(4!1​−21​b−5!1​+61​a)

x^7 的系数是：

−6!1​+4!1​b+7!1​−5!1​a

利用 x^3 和 x^5两个系数 = 0 就可以将 a 和 b 解出来了

但是，此时 x^7 的系数不为 0，所以实际上这个题是一个错题，题目中不应该是 x^5 的无穷小，如果改成 o (x^3） 就正确了

如果改成 x^3，那么下式分母是：

x5+bx7cosx(x+bx3)−(1+ax2)sinx​=0(x→0)

这个时候只用分子展开到 5 次就可以了，这样做法就正确了

7 分块矩阵的秩的结论

题目中的这个迹的条件 ABXXT 实际上是一个行向量 ABX 乘一个列向量 XT 形成的矩阵的迹，这是一个 r = 1 的矩阵的迹，所以它的迹实际上就是这两个向量的内积，所以可以改写成：

XTABX=tr(ABXXT)

同理第二个迹的条件也可以改写成：

XTABX=tr(XXTAB)

所以这个条件就是说明：

XTABX>0

这里 AB 不一定是实对称矩阵，所以这里跟二次型扯不上什么关系

只能往矩阵的迹上面靠拢

这里对于 ABX 这个列向量来说，一定有 ABX=0

也就是说对于任意的非零列向量 X 都有 ABX != 0

也就是说 ABX = 0 没有非零解，所以 AB 就是一个满秩矩阵，所以：

r(AB)=n≤r(A),r(B)⟹r(A)=r(B)=n

对于第一个矩阵

AB 可以经过行变换变成 B，所以第二行的 B 可以利用第一行消掉，因此它的秩 = r (B) + r (BC) = n + r (C)

对于第二个矩阵

这里 B 可逆，所以它的秩 = r (B) + r (AC) = n + r (C)

对于第三个矩阵

它的秩是 r (A) + r (AB) <= r <= 2 n

所以它的秩就是 2 n

因此 r 3 >= r 2 = r 1

所以 C 正确
