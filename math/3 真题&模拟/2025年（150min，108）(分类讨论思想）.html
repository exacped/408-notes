2 微分方程解的收敛性

第一题

如果根的情况是两个相异的实根，根据根的辨别，Δ>0，得到 a 的范围是 a < -1 或 a > 2；此时要想保证积分收敛，e 的系数必须<0，即两个根必须小于 0，根据韦达定理，2 a < 0 且 a + 2 > 0，所以得到 -2 < a <0；取交集，得到-2 < a < -1

如果根的情况是两个相等的实根，得到此时 a = 2 或者 a = -1，同样，要保证这个根必须小于 0，所以 a = -1

如果根的情况是一对虚根即 α±βi，此时方程的解的形式是 eαx(C1​sinβx+C2​cosβx)，首先根据根的判别得到 -1 < a < 2；此时必须保证 α<0，按照伟大定理，x 1 + x 2 = 2 a = 2 α < 0，所以 a < 0，取交集得到-1 < a < 0

以上三种情况哪种都可以，所以总的取并集，结果就是-2 < a < 0 了

第二题

在正无穷到负无穷有界，那么此时根的情况必须是一对虚跟了，解的形式是 eαx(C1​sinβx+C2​cosβx)，并且 α=0

按照判别式： a2−4b<0

按照维达定理，必须保证 α=0，所以 x 1 + x 2 = a = 0，又因为 a2−4b<0，所以 b > 0

第三题

所有的解都是 x 的周期函数，说明解的形式必须是 eαx(C1​sinβx+C2​cosβx)，并且 α=0

同第二题，a = 0 且 b > 0
