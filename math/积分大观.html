三角换元的范围和单调性问题

第二换元法，即令 x=g(t) 的使用其实有一个前提：g(t) 单调可导并且 g′(t)=0

所以在不定积分或者定积分计算的时候进行三角换元会涉及到范围的问题，比如：

a2−x2​，这个换元一般是令 x=sint，t∈(−2π​,2π​)

这样可以保证 ：

（1）sint 的取值可以取满 x 的范围（开闭无所谓，积分的值与某个点包不包含无关）
（2）sint 是单调的
（3）开方之后的 cost 是正的，不用加负号

所以不论是不定积分还是在定积分，在进行换元 x = g (t) 的时候其实只用考虑：

（1）t 的取值可以满足 x 的取值
（2）g (t) 单调

满足上述两点即可，至于开方之后的处理可以进行分区间讨论即可

通用有理函数积分法

一些基本的概念

有理函数的积分是类似与下面的式子：

∫b1​xt1​+b2​xt2​+...bn​xtn​a1​xm1​+a2​xm2​+...an​xmn​​dx

一般来讲有理函数可以分为两类：

（1）真分式，指分子的幂要小于分母的幂，比如下面的式子：

x+11​

（2）假分式，指分子的幂要大于等于分母的幂，比如下面的式子：

x2+12x2+1​

对于假分式来说，其一定可以拆成一个多项式与真分式的和，比如上面的式子可以拆成：

x2+12x2+2−1​=2−x2+11​

多项式除法

不过还有更一般的做法，可以直接用多项式除法来拆成一个多项式和真分式的和：

这里的多项式除法只要余数是小于 x^2 + 1 的式子就好了，于是可以得到：

x2+12(x2+1)−1​=2−x2+11​

再举一个多项式除法的例子：

x−3x3−12x2−42​

多项式除法如下所示：

因此将假分式化为多项式和真分式之和为：

x−3(x−3)(x2−9x−27)−123​=x2−9x−27−x−3123​

所以其实多项式除法就三个注意的步骤：

（1）被除式和除式都进行降幂排列，并且空缺的项的系数补零
（2）除法上系数的时候要保证被除式的最高幂可以被消掉
（3）一直到余数的幂小于除式，这时候除法终止

处理的一般流程

（1）拆项，如果是假分式，拆成多项式与真分式的形式
（2）对真分式的分母进行因式分解，我们可以得到一个这样的真分式：
Q(x)P(x)​

其中 Q (x) 已经进行了因式分解，这里的因式分解对二次项一定要尽可能分解，比如如果有一项是 x2−1，那么必须进行进一步的分解，变成 (x−1)(x+1)，而不能将 x^2 - 1 当作 x^2 + px + q，因为这里 x^2 + px + q 一定不能继续分解，也就是能分解成 (a + b) 的这种一次因式那就分解成一次的

就是后续对 x-a 的拆项和 x^2 + px + q 的拆项操作都是针对一个不能继续因式分解的项的操作

然后如果有相同的项，比如两个（x - a）项或者两个 (x^2 + px + q)，直接合并变成整体二次即可，但是一定要保证底数 (x^2 + px + 1) 不能继续分解

必须要保证因式分解之后都是 (x^2 + px + q)^k 和 (x + b)^k 这两种内部无法继续分解的因式的多项式组合

（3）对已经因式分解的真分式进行进一步的拆项，这一步有固定的套路：

i 如果分母中有 (x−a)，则拆出的项中有：x−aA​；如果分母中有 (x−a)2，则拆出的项有 x−aA​+(x−a)2B​；反正只要因式分解的一项是 (x−a)k，那么其就会对拆分的项贡献出：x−aA​+(x−a)2B​+(x−a)3C​....(x−a)kD​

ii 如果分母中有 x2+px+q，则拆出的项中就有：x2+px+qDx+E​；同上，如果分母中有 (x2+px+q)k，那么其就会对拆分的项贡献出：x2+px+qD1​x+E1​​+(x2+px+q)2D2​x+E2​​+....(x2+px+q)kDk​x+Ek​​；但是像这种二次的一般就只考到 k = 1，不会再多了

举个例子如下：

(x−1)2(x2+x+1)3x+6​=x−1A​+(x−1)2B​+x2+x+1Dx+E​
（4）确定拆项后的式子的系数：

也就是确定上面式子的 A，B，D，E，这里可以用待定系数法，对等式右边的式子进行通分，然后确定系数

（5）对拆分出来的式子进行积分：
∫(x−1)2(x2+x+1)3x+6​dx=∫x−1A​+(x−1)2B​+x2+x+1Dx+E​dx=∫x−1−2​+(x−1)23​+x2+x+12x+1​dx

上面的式子的前两项很简单，关键是后面的一项 ∫x2+x+12x+1​dx 的处理

类似这种式子的处理其实有一个通用过程，就是将分子拆成分母的导数和一个常数：

∫x2+x+12x+1​dx=∫x2+x+1A(x2+x+1)′+B​dx=∫Ax2+x+1(x2+x+1)′​dx+∫x2+x+1B​dx

这样做的逻辑有三个：

（1）分子是一定可以这样拆的，因为分子本来就是一个一次的式子，用 A 来控制一次项的系数，A 与导数的常数项作用得到常数，这时再加上 B 来控制常数项；所以一定可以通过 A 和 B 还原成原来的一次项

（2）拆成这样之后左边的项可以直接积分

（3）右边的项一定可以将分母写成平方式子所以我们可以得到：

∫x2+x+12x+1​dx=∫Ax2+x+1(x2+x+1)′​dx+∫x2+x+1B​dx=∫x2+x+1(x2+x+1)′​

下面的积分就非常简单了
这里比较特殊，一般情况下，比如上式的分子如果是 2 的话可以拆成：

∫x2+x+12x+2​dx=∫x2+x+1(x2+x+1)′​+∫x2+x+11​dx

进一步可以写成：

∫x2+x+12x+2​dx=∫x2+x+1(x2+x+1)′​+∫(x+41​)2+43​1​dx=ln(x2+x+1)+3​2​arctan(23​​x+41​​)

上面的所有内容就是有理积分的一般处理流程

留数法

将有理函数拆成多个积分式子确定其系数的时候不是很好做，计算量比较大，这里介绍一种留数法来快速处理

留数法就是用来确定形如 (x−a)kAk​​ 这种原来分母中的一次项拆开的项的系数的，但是对于二次项拆开的系数 x2+x+aAx+B​ 留数法一般就失效了

这里分别有几种情况来处理：

i 类似分母一次幂形成的项的系数确定，分母的项无重根

等式两边同时乘分母中对应的项，然后代值

比如：(x−1)(x−2)1​=x−1A​+x−2B​

这里等式两边乘 (x - 1) 可以得到 x−21​=A+x−2(x−1)B​，这也是一个恒成立的式子，于是我们直接取 x = 1 就得到了 A 了，同理等式两边同时乘 x - 2，然后 x 取 2 就得到 B 了

ii 类似次数大于 2 的形式的项，即分母的项有重根

比如 (x−1)2(x−2)x−3​=x−1A​+(x−1)2B​+x−2C​

对于确定分母中的单根项拆开项的系数，和重根项拆开的最高次项系数，等式两边同时乘分母中的项，然后代值即可

这里先确定无重根的项 (x - 2) 的系数，等式两边同时乘 (x - 2) 然后代入 x = 2 得到 C = -1

接着对于 B 这种重根项最高次的，也可以采用两边同时乘 (x−1)2，然后代入 x = 1, 得到 B = 2

对于确定分母中重根项拆开的低次方系数，还是通过同时乘分母中的重根项，但是需要求导将系数暴露出来，然后代值

最后是参数 A，这里的做法是还是两边同时乘 (x−1)2，然后得到：x−2x−3​=A(x−1)+B+x−2C​(x−1)2，此时两边同时求导，并代入 x = 1，这样就可以消去 B，C 两项，同时将 A 暴露出来，于是就得到 A 了

再比如一个式子：(x−1)3(x+1)x−3​=x−1A​+(x−1)2B​+(x−1)3C​+x+1D​

D 的确定方法同上，两边同时乘 x + 1 然后代入 x = -1

C 对应有重根项的最高次系数，其的确定方法同上，两边同时乘最高项 (x - 3)^3，然后代入 x = 1 得到结果

B 的确定仍然是左右两边同时乘 (x-1)^3 得到：x+1x−3​=A(x−1)2+B(x−1)+C+x+1D​(x−1)3，然后，求一次导将 B 的系数暴露出来，同时代入 x = 1 将其他项的系数归零，得到结果

A 的确定仍然是左右两边同时乘 (x-1)^3 得到：x+1x−3​=A(x−1)2+B(x−1)+C+x+1D​(x−1)3，然后，求两次导将 A 的系数暴露出来，同时代入 x = 1 将其他项的系数归零，得到结果

这种同乘最高系数的重根项，然后求导，可以保证其他的系数要么在求导的过程中归零了，要么在求导后代入 x 的值归零了，可以将待求系数暴露出来

再比如一个式子： (x−1)2(x2+x+1)3x+6​=x−1A​+(x−1)2B​+x2+x+1Dx+E​

这里可以用上面的方法快速确定系数 A 和 B，对于后面的 D 和 E，可以直接代值确定，比如得到了 A 和 B 之后直接代入 x = 0，就可以将 E 暴露出来，得到 E 之后再代入 x = 2 就可以得到 D 了

不用考虑什么单调性问题，直接凑到 dx 中

在不定积分中不用考虑区间的问题，我们可以随意选取区间，只要在这个区间中保证：

（1）g (t) 单调，有反函数
（2）方便我们的计算
