向量有关的结论汇总

3,090 字约 7 分钟2026-07-29

最基本原则

线性表示（线性相关无关），向量组的秩，方程的解，这三者可以互相转换

齐次方程组 Ax = 0 的解与向量组本身的相关性

线性相关，向量组的秩，Ax = 0 这三者的关系

向量组线性相关，说明向量组的秩 < 向量的个数，说明 Ax = 0 中未知数个数大于有效方程个数，说明 Ax = 0 有非零解

向量组线性无关，说明向量组的秩 = 向量的个数，说明 Ax = 0 只有零解

齐次方程组的解与线性相关性

向量组构成的方程为 A，则 Ax = 0 有非零解的时候向量组线性相关；Ax = 0 只有零解的时候向量组线性无关

这是因为：

对于一个方程组 Ax = 0，将 A 的每一列看作向量，x 看作一个个未知数，则可以写成：

那么，当 x 1, x 2, x 3... 不全为零的时候 A 的列向量线性相关，也就是 A 有非零解的时候列向量线性相关

当 x 1, x 2, x 3 全为零的时候 A 的列向量线性无关，也就是 A 仅仅有零解的时候线性无关

行列式与线性相关性

这是因为向量组构成的方程 A x = 0，如果只有零解，说明|A| != 0；如果有非零解，说明|A| = 0

维度和个数与线性相关性

这是因为个数 s 就是向量组的齐次方程 Ax = 0 的未知数的个数

这里有效方程个数一定小于 = n

所以未知数个数大于有效方程个数

所以一定 Ax = 0 有非零解

所以向量组线性相关

对向量组进行行变换不改变线性相关性

所谓线性相关性就是指 Ax = 0 的解，这里对 A 进行行变换是同解变换，所以不改变 Ax = 0 的解

因此也不改变 A 的列向量组的线性相关性

非齐次方程组 Ax = b 的解与单个向量 b 由 A 的列向量线性表出

b 由 A线性表出，A|b 增广的秩，Ax = b 的解的相互关系

b 可以由向量组 [α1​,α2​,α3​…]=A 线性表示，那么就是 r(A∣b)=r(A)，并且 Ax = b 有解，这三者互相等价

b 不可以由向量组 [α1​,α2​,α3​…]=A 线性表示，那么就是 r(A∣b)=r(A),r(A∣b)=r(A)+1，且 Ax = b 无解

r(A|b) 与 r(A) 的秩与 b 由 A 线性表示之间的关系

如果 b 可以由向量组 A（A 的列向量组）线性表示，则 r (A|b) = r (A)

如果 b 不可以由向量组 A（A 的列向量组）线性表示，则 r (A|b) > r (A)，其实就是 r (A|b) = r (A) + 1

这是由于 β 是一个列向量，所以 r (A| β) 其实是卡在 r (A) 与 r (A) + r (β) 之间的，即 r(A)≤r(A∣β)≤r(A)+r(β)，此时 β=0 ，所以 r(β)=1，所以即 r(A)≤r(A∣β)≤r(A)+1，当无解的时候 r (A| β)>r (A)，就是 r (A) + 1 了

A 线性无关，A|b 线性相关与 b 由 A 线性表示之间的关系

这是因为 Ax = b 只有一个唯一解

这里 [α1​,α2​,α3​…]=A 线性无关，说明 r (A) = s，而 r (A|b) 线性相关，说明 r (A|b) = r (A) = s，所以 Ax = b 有解并且唯一

矩阵方程 AX = B 与向量组之间的线性表出

线性表出，增广的秩，AX = B 的解的三者关系

向量组 B 可以由向量组 A 线性表示，说明 r(A)=r(A∣B)，说明 AX = B 有解，这三者是互相等价的

B 的列向量组可以由 A 的列向量组线性表示的充要条件

这是因为对 AX = B 形成的增广阵 A|B 进行初等变换，将 A 变成阶梯型矩阵

于此同时，由于 B 的每一列都可以由 A 线性表示，即 Ax = bi 都有解，所以 B 的每一列 bi 在随着 A 变成阶梯型的时候会保证 r (A|bi) = r (A)，即 bi 的非零行一定不会超过 A 变成阶梯型矩阵的时候的非零行

这样 B 随着 A 变成阶梯型矩阵，他的非零行也不会超过 A 变成阶梯型的非零行

所以 r (A) = r (A|B)，也就是这个结论了

反过来也成立，相同的理解方式

向量组的线性表示与两者的秩关系，被线性表示的向量组的秩更小

这是因为 AX = B 有解，根据矩阵相乘，秩越乘越小，所示 r (B) <= r (A)，也就是被表出的向量组的秩更小

秩与相关性

向量组整体的秩一定大于等于部分向量组的秩

这里可以用矩阵的角度来理解

整体的大的向量组构成的矩阵的秩就是这个向量组的秩

那么这个矩阵中抽掉一些列之后就是部分向量组了，这个部分向量组构成的矩阵的秩一定不会大于原来的矩阵的秩，因为秩是最大阶的非零子式，你抽掉一些列之后非零子式必然不会变大，甚至会变小

所以整体的大的向量组的秩一定大于等于这个整体中部分向量组的秩

向量组等价的充要条件（定义）

两个向量组之间可以互相表示

向量组等价的充分条件

向量组等价的充要条件-三秩相等

整体与部分定理

延长与缩短定理

延长组线性相关 => 原向量组线性相关（缩短后线性相关）

这个结论用方程组的解来理解

延长组作为系数矩阵构成的方程组有非零解，将其维度缩小了，相当于这个方程组砍掉了一些方程，但是这个非零解仍然是砍掉一些方程之后的方程组的非零解，即维度缩小之后的向量构成的系数矩阵对应的方程组仍然有非零解，所以线性相关

减少维度相当于减少方程，相当于减少约束，那么解集一定会在原来的基础上扩大，原来就有非零解，解集扩大，就一定会再增加一些解

原向量线性无关 => 延长组线性无关

原向量线性无关，说明这些向量作为系数矩阵构成的方程组就只有零解；那么延长之后，相当于多加了一些方程进去，同样不可能有非零解，因为如果有非零解那这个非零解就不满足原向量组构成的方程；所以延长组仍然线性无关

增加维度相当于增加方程，相当于在原来的解集基础上增加约束，这样一定会进一步缩小解集，而原来的就只有零解，所以增加约束之后一定还是只有零解

以少表多，多必相关

第一句话，用反证法

假设 β1​,β2​,…βt​ 线性无关，因此 r(β1​,β2​,…βt​)=t

根据被表示的向量组的秩一定更小 (见上文的矩阵方程与向量组的互相表示)，可以得到：

r(β1​,β2​,…βt​)=t≤r(α1​,α2​,…αs​)≤s

与命题条件矛盾，所以 β1​,β2​,…βt​ 一定无关

第二句话

很好证明，被表示的向量组的秩一定更小一些，即：

r(β1​,β2​,…βt​)=t≤r(α1​,α2​,…αt​)≤s

零向量与线性相关性的一些结论

（1）如果一个向量组中含有 0 向量，则这个向量组一定是线性相关的

（2）两个向量线性相关，则可能两个向量成比例（非 0）；也可能两个向量中含有一个零向量

（3）0 向量可以由任意的向量组线性表出

（4）0 向量与任意的向量正交

（5）只含有 0 向量的向量组的秩 = 0，没有极大无关组
