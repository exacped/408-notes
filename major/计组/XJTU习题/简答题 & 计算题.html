什么是CISC？什么是RISC？两者各有什么特点，分别举三条

CISC：复杂指令系统计算机

基址寻址和变址寻址有哪些区别？

（4）基址寻址一般用于动态定位，变址寻址一般用于数组和串的处理

段寻址的计算原理是什么

（1）指令按照正常的寻址方式得到一个暂时的有效地址 EA'，也就是段内偏移，这是其他寻址方式得到的有效地址
（2）段地址存放在一个默认的段寄存器 DS 中，暂时的有效地址和段地址都和机器字长一样
（3）段地址和暂时的有效地址错位相加得到一个更大的物理地址，比如 段地址 * 16 + 段内偏移 = 物理地址 段地址左移四位与偏移地址相加

集中式总线控制的常用判优方法以及各自特点

（1）链式查询模式：
通过一条判断优先级的链路逐个对所有主模块进行串行查询，通常里控制器越近的主模块优先级越高
优先级固定，查询速度慢，不灵活

（2）计数器定时查询模式：
总线控制器中设置一个计数器用作查询，计数器的值作为地址，主模块地址跟计数器的值相同的模块获得总线控制权
灵活性高，可以方便改变响应次序，硬件复杂

（3）独立请求方式：
每个主模块都可以单独向控制器请求总线控制权，总线控制器中设置判优电路来对主模块的请求进行排序，并向优先级最高的模块发送总线允许信号
硬件开销最大，响应最快

总线通信是什么？常见的总线通信方式？

总线通信就是在一次总线传输过程中，如果涉及两个或两个以上部件，那么部件之间就需要进行操作时间协调来保证总线传输操作的正确，这个操作协调就是通信

总线的异步通信和同步通信的区别是什么？

半同步通信是什么？

半同步通信是异步通信和同步通信的结合，其既有同步通信那样统一的时钟控制，又像异步通信那英允许传输时间不一致；其保留了同步通信控制简单的优点，又具有异步通信的灵活

显示器中显存 VRAM 中存放的是什么？其大小如何计算？

VRAM 用来存放整个屏幕的字符信息，即整个屏幕的 ASCII 代码，因此其大小与屏幕的字符个数相对应，通常西文字符以 ASCII 码的形式存放在 VRAM 中，因此 VRAM 中的一个存储单元的最小宽度是一个字节

显存 VRAM 种的字符地址与屏幕上字符怎么对应？

VRAM 中的每个单元的地址是由屏幕上字符的行和列决定的，即 VRAM 的地址为字符所在的行号 * 一行的字符个数 + 字符所在的列号

显示器中字符发生器 ROM 中存放的是什么？其大小如何计算？

字符发生器的作用就是将 VRAM 中的字符编码（ASCII 码）转化成二进制信息（也就是对应点阵信息）存放到 ROM

对于字符发生器的容量，其取决于整个字符集的大小和点阵规模，一个点阵的点就表示二进制的一个位存放到发生器 ROM 中

比如一个字符集有 95 种字符，每个字符在显示屏上的点阵是 7（列）* 9（行），并且每个字符之间的间隔是一个像素点，那么一个字符占据的点阵规模就是 8（列）* 9（行）

所以这个 ROM 的大小就是 95 * （7 + 1） * 9 bit = 855 B

控制屏幕同步的计数器有哪些？分别有什么作用？

点计数器：电子束每扫描屏幕上的一个像素点，点计数器++

字计数器：电子束每扫描屏幕上的一个字符窗口宽度（也就是字符宽度）的像素点，字计数器++

行计数器：电子束每扫描屏幕上的一行像素点，行计数器++

排计数器：电子束每扫描屏幕上的一排字符，排计数器++

计数器的模是什么意思？以及各自的模分别是什么？每个计数器输出一次表示什么？

模其实就是计数器的容量大小，每个计数器不停自增，超过这个容量之后从头计数，并输出一个信号

点计数器的模：字符窗口的宽度，点计数器输出一次表示扫描了一个字符宽度的像素点

字计数器的模：一行的字符个数加上水平回扫的时间，字计数器输出一次表示扫描了一行的像素点

行计数器的模：字符窗口的高度，行计数器输出一次表示扫描了一排的字符

排计数器的模：屏幕的字符排数加上垂直回扫的时间，排计数器输出一次表示扫描了整个屏幕的字符

上面这些计数器，前面的计数器输出一次给后面的计数器，于是后面的计数器++

三种常见的 IO 数据传送控制方式以及各自特点

（1）程序查询方式
即在现行程序中插入一段程序来进行 IO 数据交换，交换完毕之后由继续执行现行程序
CPU 和 IO 设备串行工作，当需要传输数据的时候如果 IO 设备没有准备好，CPU 需要反复查询 IO 设备是否准备好，且不能做其他的事情，即踏步等待，CPU 效率低

（2）中断方式
需要数据传输并启动 IO 之后 CPU 不必等待 IO 设备准备好，而是继续允许现行程序，当 IO 设备准备好了之后向 CPU 发送中断请求
CPU 和 IO 设备并行工作，CPU 的效率高

（3）DMA 方式
主存和 IO 设备之间直接有一条数据通路，CPU 不参与 IO 和主存之间的信息交换
CPU 和 IO 设备的并行程序进一步提高，CPU 的效率进一步提高

请从数据传输依赖软件 or 硬件，数据传送基本单位，并行性，主动性，传输速度这几个方面比较三种 IO 数据传送控制方式

什么是中断？

完整的中断过程是什么？

简化版本如下（背）：

  1. 中断请求
  2. 中断判优
  3. 中断响应
    1. 关中断
    2. 保护程序断点，PSW（程序断点和 PSW 入栈）
    3. 获得中断服务程序入口地址
  4. 中断处理
    1. 保护现场（保存程序中的一些数据）
    2. 开中断
    3. 中断处理（开中断之后这个过程允许多重中断）
    4. 关中断
    5. 恢复现场
  5. 中断返回
    1. 程序断点和 PSW 出栈
    2. 开中断
NOTE

一次完整的中断过程分为5个阶段：

（1）中断请求

IO设备完成操作之后就向CPU发送中断请求，IO接口中有一个中断请求触发器INTR，INTR = 0表示没有请求，INTR = 1表示有请求

同时CPU还可以决定是否响应这个请求，IO接口中还有一个中断屏蔽触发器MASK，MASK = 1表示这个IO的中断请求被屏蔽，CPU不理他，MASK = 0表示CPU对这个中断表示响应

（2）中断判优

多个中断源同时请求的时候CPU需要对这些中断源进行判优排队，排队主要有串行排队和并行排队两种方式，可以由硬件也可以由软件实现

（3）中断响应

中断响应就是CPU受到中断源发出的请求之后开始有所动作，当然CPU自已也可以决定不采取响应，CPU有一个中断允许触发器EINT，EINT = 0表示禁止中断，无论IO怎么法请求CPU都没有动作，EINT = 1表示允许中断；CPU在每条指令执行完了之后都会查询是否有中断请求

在中断响应中CPU主要执行三个操作，这三个操作是由硬件自动执行的，就好像有默认的指令一样，所以称为隐指令：

i 关中断

即将EINT设置为0，表示CPU正在处理中断，以免别的中断过来有冲突

ii 保护程序断点，PSW

iii 获得中断服务程序地址

获得的方法主要有两种，软件查询法和硬件向量法

（4）中断服务 - 执行中断服务程序

CPU在执行完响应操作得到中断服务地址之后就开始执行中断服务程序，中断服务程序要完成三个工作：

i 保护现场
保护现场主要是保存CPU正在运行的程序的位置以及程序中的一些内容，其有两个方面：

保存断点和程序状态字(PSW)，这一步通常在CPU响应中断的时候由隐指令完成，因此保护现场的一些操作主要跟程序内部的内容有关

（1）分散互联结构

  1. 没有总线
  2. 有一个 MDR，但是只有从存储器读数据的时候才会使用
  3. ALU 的输入端有两个暂存器 A 和 B，有结果暂存器 ALUOut

（2）单周期结构

  1. 一根总线，非常好辨认
  2. 存储器有 MDR 和 MAR，并且所有数据（指令和操作数）的读取都必须经过这两个暂存器与存储器交互
  3. ALU 有两个暂存器 A 和 B，没有结果暂存器 ALUOut
NOTE

单总线与分散互联的结构相比其硬件结构更加规整，但是由于存在总线竞争，因此指令的一些阶段需要的时钟周期更多

（3）双总线结构

  1. 两根总线和一个总线桥 G
  2. 存储器有 MDR 和 MAR，并且所有数据（指令和操作数）的读取都必须经过这两个暂存器与存储器交互
  3. ALU 的输入端由两根总线代替，但是需要一个结果暂存器 A
NOTE

双总线与单总线相比增加了一条总线，显然就减少了总线竞争，指令阶段所需的时钟周期就少一些，但是会带来硬件的复杂度上升

控制冒险：主要是分支执行指令，导致之前的执行过程无效

简述组合逻辑设计方法和微程序设计方法，及其特点？

组合逻辑：
控制单元是一个组合逻辑网络，产生所需要的全部控制信号
（1）设计思想简单，但是设计过程繁琐，修改困难

（3）在后来的 RISC 计算机中普遍使用

（1）设计复杂，硬件结构简单
（2）控制信号产生速度慢
（3）在 CISC 计算机中普遍使用

微操作控制字段：产生全部微操作的控制信号

顺序控制字段：指出下一条微指令的地址

微操作控制字段的设计方法有哪些？各有什么特点？

（1）直接编码方式：一个位表示一个微命令，这样会导致微指令很长
（2）字段直接编码方式：一个字段表示一个微命令，互斥的微命令放在一个字段中，不同字段的微命令相容，这样压缩了微指令的长度
（3）字段间接编码方式：不同字段合起来决定一个微命令，这样微指令长度进一步压缩
（4）混合编码方式：当字段长度减少到 1 位的时候就变成了直接编码方式了，这种方式兼顾了灵活性和执行速度

顺序控制字段的设计方法有哪些？各有什么特点？

（1）直接表示方式：微指令的顺序控制字段直接给出后序地址

（2）增量方式：就是将微指令控制器中的 CMAR 当作 PC 一样让其具有自增的功能，但是顺序微指令和转移微指令的格式不统一，转移灵活性差

（3）增量与下址字段相结合：指令格式统一，但是只能实现两路转移

（4）断定方式：可以实现微程序的多路分支转移
