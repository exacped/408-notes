然后是第二个小问，这里OF标志位按照平时学过的知识，它的表达式应该是次高位进位和最高位进位的异或，但是这里无法用这两个异或来表示，而且题目也说了只能根据A15, B15和F15来表示，所以得思考别的表示方法

这里题干有提示，需要分成A + B和A - B两种情况，那我们就分成这两个情况分别来讨论

当A + B的时候此时又分为4种情况

A > 0, B > 0，此时可能发生溢出，溢出的情况是F15 = 1（两个正数加法变成负数），这个时候是 A15​ˉ​B15​ˉ​F15​，也就是说只有 A15​ˉ​B15​ˉ​F15​ 这样的表达式才能保证只有单单这种情况溢出位为1，即A15 = B15 = 0，但是F15 = 1的时候溢出位为1

当A > 0, B < 0，不可能溢出

当A < 0, B > 0，不可能溢出

当A < 0, B < 0，此时可能溢出，溢出的情况是F15 = 0（两个负数加法变成正数），这个时候的表达式是 A15​B15​F15​ˉ​，这个时候A15 = B15 = 1，F15 = 0

也就是说当A+B的时候OF = A15​ˉ​B15​ˉ​F15​+A15​B15​F15​ˉ​，当溢出的时候OF就是有效的，别的情况就是不溢出，不溢出这个表达式就是0

当A - B的时候此时也分为4种情况

A > 0, B > 0，不可能溢出

A > 0, B < 0，可能溢出，溢出的情况是F15 = 1（一个正数 - 一个负数，结果变成负数的情况），此时的情况是 A15​ˉ​B15​F15​

A < 0，B > 0，可能溢出，溢出的情况是F15 = 0（一个负数 - 正数，结果变成正数的情况），此时的情况是 A15​B15​ˉ​F15​ˉ​

A < 0, B < 0，不可能溢出

所以当A - B的时候OF = A15​ˉ​B15​F15​+A15​B15​ˉ​F15​ˉ​，当溢出的时候OF就是有效的了，别的情况就是不溢出，不溢出这个表达式就是0

这道题考察的更加深入，是对带符号加减法溢出判断的最本质考察

因为CPU是单总线结构，每一时刻总线上只有一个数据有效，ALU不可能同时利用总线将两个操作数输入道ALU的两端，只能先保存一个，然后用总线再送下一个，所以需要暂存器Y

暂存器Z的作用是，在执行ALU计算的时候总线仍然被使用传递操作数B，这里的计算是一个过程，操作数B需要总线有效保持一段时间，而计算结果也是慢慢产生的，如果ALU计算结果立刻被传送到总线上的话可能会覆盖掉操作数B，简单来说就是ALU 的输出端产生运算结果，但由于总线正 被占用，因此需要暂存器 Z，以缓存 ALU 的输出端数据

缓冲区大小是8B

一个扇区的大小是512B

缓冲区每满了一次就需要进行一次DMA传送，所以发送了64次总线请求

DMA必须获得总线使用权，因为此时数据缓冲区已满，DMA如果不及时将数据拿走放到主存，那么此时外设仍然在工作，仍然在往缓冲区写数据，这就会造成没有被拿走的数据被覆盖

磁盘的传送以什么为单位？DMA传送的基本单位是什么？

扇区是磁盘最小的物理存储单元，是磁头从磁盘中读取数据的最小单位（一般512B），即磁头每次从磁盘中读取数据，都是一个扇区一个扇区读的

DMA 在数据传输阶段每次传送的是一个字，具体来说就是 IO 接口中的 IO 端口中的一个字数据（IO 接口中的数据缓冲寄存器中的一个字），每当外设准备好了一个字之后，就通知 DMA 控制器，由 DMA 控制器发出总线请求，传输一个字，传输完毕交出总线控制权；在这道题目中就是一个缓冲区大小的数据
