# 22408 备考笔记

复旦大学 22408 考研笔记网站：数学（一）+ 专业课 408，由 Obsidian Markdown 笔记静态生成。

**在线访问**：https://exacped.github.io/408-notes/

## 内容

- **数学（一）**：基础、强化、历年真题与模拟卷台账
- **专业课 408**：数据结构、操作系统、计算机组成原理、计算机网络
- 148 篇笔记 · 约 148 万字 · 6500+ 处 KaTeX 公式 · 50 套真题/模拟

## 功能

- 全站检索（快捷键 `/`）
- 章节目录树、页内目录、当前位置高亮
- 阅读进度与已读标记（存于浏览器 localStorage）
- 真题台账：年份 / 用时 / 得分
- 夜读暗色模式

## 技术

纯静态站点，无框架：Node.js 自写生成器扫描 Markdown → markdown-it 渲染（自定义 KaTeX / Obsidian 语法插件）→ 输出 HTML。检索索引按科目分片注入，本地双击 `index.html` 即可离线使用（图片存放在图床）。

## 更新

改完笔记后运行 `note-site/deploy.bat`：自动重新构建并推送到本仓库，GitHub Pages 约 1 分钟后更新。
